# OncoVariant SQL — Somatic Mutation Landscape of a Pan-Cancer Cohort

A SQL-first analysis of a targeted tumour-sequencing cohort: **660 patients across
4 cancer types** (breast BRCA, lung adenocarcinoma LUAD, colorectal COAD, melanoma SKCM)
with clinical data, ~2,600 raw somatic variant calls and gene-expression values.

The project covers the full analyst workflow: **schema design → ETL & cleaning →
quality control → analysis → biological interpretation**, all in SQL (SQLite).

> **Data note:** the dataset is synthetic. It is generated by `scripts/generate_data.py`
> using published driver frequencies, real hotspot mutations and approximate
> GRCh38 gene coordinates, so the analysis reproduces known cancer biology without
> patient-privacy constraints. The schema mirrors the MAF/clinical files on
> [cBioPortal](https://www.cbioportal.org/datasets), so it can be pointed at real TCGA data.

## Schema

```
patients 1──* samples 1──* variants   *──1 genes
                      1──* expression *──1 genes
```

| Table | Grain | Key columns |
|---|---|---|
| `patients` | 1 row / patient | sex, age, smoking, stage, vital status, OS months |
| `samples` | 1 row / tumour sample | cancer type, tumour purity, MSI status |
| `genes` | 1 row / gene | chromosome, coordinates, protein length, role (Oncogene/TSG/Passenger) |
| `variants` | 1 row / raw variant call | locus, ref/alt, variant class, protein change, depth, VAF, filter |
| `expression` | 1 row / sample × gene | TPM |

## How to run

Requires only Python 3 and the `sqlite3` CLI (both preinstalled on macOS).

```bash
./run_all.sh                 # generate data, build onco.db, write results/*.txt
sqlite3 -header -column onco.db   # explore interactively
```

Charts (Python + pandas + matplotlib, queried straight from `onco.db`):

```bash
python3 -m venv .venv && .venv/bin/pip install pandas matplotlib
.venv/bin/python scripts/plots.py           # writes figures/*.png
.venv/bin/python scripts/plots.py ../assets/onco   # or straight into the portfolio site
```

## Key findings

**1. Data quality.** 2,590 raw calls → 2,161 analysis-ready variants. 394 calls failed
QC (mean depth 11× and VAF 2.5%, vs 252× and 31% for kept calls, which is typical of sequencing
artefacts), and 35 duplicate calls from pipeline re-runs were removed. Sex was recorded
inconsistently (`F`, `female`, `MALE` …) and was normalised during load.

**2. Each cancer type has its expected driver profile.**

| Cancer | Top drivers (% of tumours) |
|---|---|
| BRCA | TP53 34.5 · PIK3CA 33.2 · GATA3 12.7 · CDH1 10.9 |
| LUAD | TP53 39.4 · KRAS 28.9 · STK11 24.4 · KEAP1 20.6 · EGFR 13.3 |
| COAD | APC 83.3 · TP53 62.7 · KRAS 39.3 · PIK3CA 22.0 |
| SKCM | BRAF 54.5 · NF1 26.4 · TP53 21.8 · NRAS 16.4 |

Tumour suppressors are inactivated by truncation (49% of their mutations are truncating),
while oncogenes are activated by point mutations (3.5% truncating).

**3. Hotspots.** BRAF V600E is the most recurrent mutation (67 tumours, 78% of all BRAF
mutations). KRAS G12C, which can be targeted with sotorasib, makes up ~12% of KRAS mutations in LUAD and COAD.

**4. Mutational burden.** Melanoma has the highest median TMB (10.7 mut/Mb). In colorectal
cancer, **MSI-high tumours average 29.5 mut/Mb vs 3.1 for MSS**, and 96% of them are TMB-high (≥10),
the group most likely to respond to immune checkpoint inhibitors. TMB-high tumours also
show higher CD8A (T-cell) expression.

**5. Mutual exclusivity.** The strongest signals are BRAF–NRAS in melanoma (0 co-mutated vs
9.8 expected), EGFR–KRAS in lung (0 vs 6.9) and PIK3CA–PTEN in breast (0 vs 3.6). In each pair
both genes act in the same pathway (MAPK or PI3K), so one hit is enough.

**6. Smoking and lung cancer.** EGFR mutations occur in 36% of never-smokers vs 8% of
ever-smokers. KRAS mutations show the opposite pattern (9% vs 33%), and smokers have about 10× the TMB.

**7. Survival.** Using a Kaplan–Meier estimate computed in SQL, median overall survival is
**36.0 months for TP53-mutant vs 47.5 months for TP53 wild-type** patients
(5-year survival 35% vs 41%). TP53-mutant tumours also show ~2× higher MKI67
(proliferation) expression (log2FC 1.09). Stage is the dominant prognostic factor
(mortality rises from 8.6 to 70.9 deaths per 100 person-years from stage I to IV).

## Limitations and next steps

- **Small panel:** TMB is measured over ~0.19 Mb, so each mutation adds ~5.4 mut/Mb.
  Real panels such as MSK-IMPACT (~1.1 Mb) give finer resolution.
- **No significance testing:** the weaker co-occurrence pairs (|log2OR| ≈ 1) are likely
  noise. A next step is Fisher's exact test with FDR correction in Python/R.
- **Confounding:** TP53 status differs by cancer type. The stratified mortality table in
  `07` addresses this partly; a Cox model adjusted for stage and cancer type would be the
  rigorous follow-up.
- **Real data:** swap in a TCGA PanCancer Atlas study from cBioPortal
  (`data_mutations.txt`, `data_clinical_patient.txt`) and the same queries apply.
